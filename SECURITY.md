# Security Policy

## Reporting a vulnerability

For sensitive reports, use this repository's GitHub private vulnerability reporting channel in the Security tab. If private reporting is enabled, you can open a report directly at:

https://github.com/allsmog/agentic-fuzz-engine/security/advisories/new

Please include a clear description, affected revision, reproducible steps or a minimal proof, and the expected security impact. Do not include sensitive details in public issues.

## Scope and handling

Reports about this repository's source, packaged command-line tools, and plugin files are in scope. Reports are reviewed privately when possible; public disclosure timing is coordinated after assessment and a fix plan.
